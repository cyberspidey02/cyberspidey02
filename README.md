# Hi, I'm CyberSpidey 🕷️

---

I'm an aspiring **Ethical Hacker / VAPT Analyst** pursuing an **M.Sc. in Cyber Security** at the **National Forensic Sciences University (NFSU), Goa**. I hold the **EC-Council Certified Ethical Hacker (CEH)** certification and focus on **Web Application Pentesting, API Security Testing, and Network Vulnerability Assessment**, following OWASP-based methodology to turn attack surfaces into evidence-backed findings.

## 🕸️ What I'm working on

- **Web Application Pentesting**: manual and tool-assisted testing against the OWASP Top 10
- **API Security Testing**: hunting Broken Object Level Authorization (BOLA) and other OWASP API Top 10 issues
- **Network Pentesting & Vulnerability Assessment**: recon-to-report VAPT methodology across lab and CTF targets
- **Offensive security tooling**: building custom Python-based scanners and intentionally vulnerable lab targets to test against
